A guided build workflow

Choose a supported system, provide the required source and compatible base or runtime, customize the presentation, and build. Simple mode keeps everyday choices direct while Advanced mode exposes additional controls.

  • Custom icons, boot images, frames, artwork, and supported boot sounds
  • Readiness and storage checks before work begins
  • Batch preparation, output validation, and support bundles
  • SD-card export and optional local-network transfer tools

Platforms

Desktop releases are available for Windows, macOS, and Linux. Android is being prepared for Google Play with phone, tablet, and foldable layouts. Platform capabilities can differ while mobile release work is completed.

Requirements and compatibility

Games, base titles, emulator runtimes, firmware, and keys are not included. Use only files you are legally permitted to use. Compatibility depends on the selected game, base, runtime, and options, and generated-package validation cannot guarantee that every combination will run on Wii U hardware.

Support and privacy

Report reproducible problems through GitHub or email support. Include the selected console, current build stage, and an exported support bundle when available.
